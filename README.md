## How to Run the Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/rizalyncantong5-cloud/ELEC4-Python-Cantong.git
   ```

2. Open the project folder:

   ```bash
   cd ELEC4-Python-Cantong
   ```

3. Run an activity using Python:

   ```bash
   py set1/p1/p1_grade_calculator.py
   ```

   Replace the file path with the activity you want to run.
